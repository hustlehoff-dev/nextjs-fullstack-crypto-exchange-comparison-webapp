# 🔍 CryptoDepths – Crypto Exchange Comparator

**CryptoDepths** is a web app for comparing cryptocurrency exchanges, in early stage of development.

### Core Features

- Compare crypto exchanges: fees, volume, available trading pairs, and more
- Live Top 100 cryptocurrencies list with key market data
- Fast filtering and sorting
- Responsive UI for desktop and mobile
- SEO-optimized with Next.js

### Tech Stack

Next.js · React · TypeScript · React Query · Sass · CoinGecko API

### Coming Soon

- Exchange API integrations (more data sources)
- Express.js backend with database (MongoDB)
- User accounts and saved comparisons
- Premium tools and analytics
